# SBC_Church_App
Church app, remade to fit our needs.
This is project is essentially a remake of the church app that already exists (made for us by paypal). It needs to be remade/updated to include features that would make it easier for the church leadership to send updates, schedule meetings, review requests, etc from the members of the church

## Scope
### For Pastors:
- member info (name, email, phone number, current address, member status: active, unbaptized, excomm., warnings, etc)
- user elevation (admin priviledges for pastors/deacons). elevated users can edit any church member info for updates
- mass text/email update, maybe newsletter (to be used instead of Viber)

### For Media Dept.:
- update website, which then updates app
- current announcements need to update the scrolling list/home page
- button to switch the default language of the app (or create a way to use the phone default settings
